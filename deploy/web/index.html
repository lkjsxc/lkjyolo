実装、バグ修正、ビルド、テスト。ChatGPT・Codexから、自分専用の永続Linux環境で作業できます。ファイルも実行履歴も、あなたの環境に残ります。

アカウントを申請Coderにログイン

使い始めるまで

自分のアカウントを用意

初めての方はアカウントを申請してください。管理者の承認後にログインできます。既存アカウントがあれば、そのまま使えます。

自分の開発環境を作成

CoderのTemplatesから「tiered-workspace」を選び、環境名を「lkjyolo」にします。既存の環境が1つだけなら、その環境を使えます。CPU・メモリ・ディスクは割り当て済みの利用枠に従います。

ChatGPT・Codexから接続

ChatGPTではPluginsの「＋」→「Add custom MCP server」で、名前を「lkjyolo」、認証を「OAuth」にして追加します。自分のCoderアカウントで許可し、プラグインをインストールしてください。

https://coder.lkjsxc.com/lkjyolo/mcp

スコープの入力が必要な場合は coder:all。カスタムMCP接続を追加できるアカウント・組織設定が必要です。

いつもの言葉で依頼

Workのチャットで「@lkjyolo」を選び、「作業用フォルダーを確認して」と依頼します。新しい環境では初回に実行基盤を自動で準備します。

接続前に知っておくこと

他の人と環境は共有されますか？

ログインした本人が所有するワークスペースに接続します。他人のファイル・認証情報・実行履歴は共有しません。GitHubなど外部サービスへのログインも各自で行ってください。

環境が複数ある場合は？

管理者が指定した環境、次に「lkjyolo」という名前の環境を選びます。どちらもなく複数ある場合は実行せず、実行先の指定を案内します。

長い処理や、環境の停止は？

チャットの呼び出しが終わっても処理は続けられます。ワークスペースの停止・再起動では実行中の処理は終了します。永続ディスク上のファイルと保存済み履歴は残ります。

プラグインZIPから導入したい

ローカルプラグインに対応したCodexなどでは、配布用ZIP（0.6.0）を利用できます。各自のOAuth接続が必要です。公開ディレクトリへの掲載とは別の配布方法です。
